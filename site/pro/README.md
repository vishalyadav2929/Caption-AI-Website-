# Pro editors

Open-source apps by the ArtCraft team (https://getartcraft.com), built for the browser and hosted
here unchanged except as noted. Each folder keeps its licence (MIT or Apache-2.0), NOTICE and
attribution files.

- `photo/`: PhotoCraft 0.9.0 (https://github.com/storytold/photocraft). Modified: one line in
  `crates/engine/src/presets/mod.rs` (the `export_presets` field missing from `Persisted` in
  `load_presets_json`) so the source builds.
- `video/`: FilmCraft 0.8.0 (https://github.com/storytold/filmcraft). Unmodified.
